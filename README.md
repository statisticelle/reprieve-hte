# reprieve-hte
This repository contains R code used for causal survival forest analysis of 5-year incident MACE and diabetes in the REPRIEVE trial. It is intended to provide more details on analysis decisions and model hyperparameters. Note that data is sensitive and is not made publicly available by this repository. De-identified data may be downloaded or requested elsewhere.

**Corresponding Paper:** Davies Smith et al. Characterizing the Heterogeneity of Statin Effects to Personalize Cardiovascular Disease Prevention in People with HIV. *Pending submission.*
